# Ozzie & Grady's Sliding Puzzle

A mobile sliding tile puzzle game built with Expo / React Native.

## Features

- **3×3, 4×4, and 5×5** grid sizes
- **Row/column multi-tile shift** — tap any tile in the same row or column as the empty space and all tiles between slide at once
- **300-move guaranteed-solvable shuffle**
- **Timer & move counter**
- **Spring animations** via react-native-reanimated
- **Haptic feedback** on tile taps and win
- **Rainbow restart button** that cycles through colors every 800 ms
- Dark slate/indigo theme

## Getting Started

```bash
npm install
npx expo start
```

Scan the QR code with **Expo Go** on your phone, or press `i` for iOS simulator / `a` for Android emulator.
